# FindYourCC — Independent Indian Credit Card Guide & Stack Optimizer

An independent, affiliate-free Indian credit card guide and comparison platform. Real earn rates, fine print, reward exclusions, lounge rules, and RuPay UPI compatibility for 120+ credit cards across 22 banks.

## Features

- **Explore & Filter (`/explore`)**: Multi-attribute filtering (issuers, fees, salary, CIBIL, lounge access, RuPay UPI, forex, etc.) with fuzzy search.
- **Card Detail (`/card/$id`)**: Real earn rates, exclusion fine print, accelerated earn caps, and custom ROI calculator.
- **Side-by-Side Compare (`/compare`)**: Compare up to 4 cards, metric highlighting, and PNG export.
- **Reward Calculator (`/calculator`)**: Category spend sliders, perk values, and break-even calculations.
- **Card Match Quiz (`/match`)**: 8-step questionnaire mapping spending habits and credit profiles to optimal cards.
- **Card Stack Builder (`/wallet`)**: Portfolio tracker for owned cards, category coverage heatmap, and gap analysis.
- **Learn Hub (`/learn`)**: CIBIL utilisation & interest calculators, glossary, and fine-print guides.
- **Custom Dataset Tools (`/settings`)**: Export, modify, and re-import custom JSON datasets locally.
